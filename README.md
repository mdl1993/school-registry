# School Registry App

A small web app built with **SvelteKit**, **TailwindCSS**, and **TypeScript** for managing a simple school registry.

## Features
- View students and teachers in tables
- Forms to add a students and teachers

## Technical Requirements
- Framework: SvelteKit
- Styling: TailwindCSS
- Typing: TypeScript
- Data: mock in-memory services (no backend, no APIs)

## Getting Started
Clone the repository and install dependencies:

```sh
git clone https://github.com/mdl1993/school-registry.git
cd school-registry
npm install
npm run dev
